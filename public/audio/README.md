# Audio Files

This directory should contain sample MP3 audio files for the music player.

## Required Files

The seed script expects the following files:
- `sample1.mp3`
- `sample2.mp3`
- `sample3.mp3`

## Where to Get Sample Audio

You can use royalty-free audio samples from:
- **Free Music Archive**: https://freemusicarchive.org/
- **Incompetech**: https://incompetech.com/music/royalty-free/
- **Bensound**: https://www.bensound.com/
- **YouTube Audio Library**: https://www.youtube.com/audiolibrary

## Important

Make sure you have the rights to use any audio files you add to this directory. All files should be in MP3 format for best compatibility.

For testing purposes, you can use any short (1-5 minute) MP3 files and rename them to match the expected filenames.
