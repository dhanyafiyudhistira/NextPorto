# Todo App

A minimal todo list built with Vite, React, and TypeScript. Tasks are stored in the browser's localStorage.

## Features

- Add, edit, delete, and toggle tasks
- Clear completed tasks
- Filter tasks (All / Active / Completed)
- Task counter
- LocalStorage persistence with debounced autosave
- Responsive monochrome UI

## Development

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the development server:

   ```bash
   npm run dev
   ```

3. Lint the code:

   ```bash
   npm run lint
   ```

4. Run tests:

   ```bash
   npm test
   ```

## Build

```bash
npm run build
```
