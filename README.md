# Retro Chess

Minimal Expo + TypeScript chess app with retro styling. Features a basic
game board powered by `chess.js`, move list, clocks and QR-code invite
stubs.

## Run

```bash
npm install
npx expo start
```

## Notes

This is a simplified demonstration and does not implement all production
features. Online play, full retro theme assets and exhaustive rule tests
would need further work.
